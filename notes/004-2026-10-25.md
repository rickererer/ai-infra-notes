# 2026-10-25 线性回归：从数学假设到从零实现

对应 d2l 3.1 线性回归、3.2 从零开始实现。

## 仿射变换不等于线性变换

模型写的是 `y = Wx + b`，教材叫它仿射变换（affine transformation），不叫线性变换。差别在那个 `b`。

数学上“线性”要求两条：`f(x₁+x₂) = f(x₁)+f(x₂)`，以及 `f(0) = 0`。

实测（`W = [[1,0],[0,2]]`，`b = [1,1]`）：

```
f(x₁)       = [2., 5.]
f(x₂)       = [4., 3.]
f(x₁+x₂)    = [5., 7.]
f(x₁)+f(x₂) = [6., 8.]     差一个 b
f(0)        = [1., 1.]     不是零
```

去掉 `b` 之后两条都成立。

**在深度学习里没人纠正这个叫法**，`nn.Linear` 名字就叫 Linear，实际是仿射。知道差别就行，考试和面试偶尔会问。

有个办法能把它变回纯线性变换，叫齐次坐标：给输入末尾补一个 1，矩阵右侧加一列 `b`，底下一行 `[0,0,1]`：

```
[[1, 0, 1],      [x₁]     [x₁ + 1]
 [0, 2, 1],  @   [x₂]  =  [2x₂ + 1]
 [0, 0, 1]]      [1 ]     [1      ]
```

图形学里所有变换都这么写，深度学习里没必要，直接把 `b` 当独立参数更省事。

仿射变换保持直线和平行，但**不能把直线弯成曲线**。这是单靠线性层做不了复杂任务的根本原因，也是 ReLU 存在的理由。

## 为什么用平方误差：正态噪声假设

教材那套推导回答的是“为什么偏偏用平方，不用绝对值”。

假设观测噪声服从正态分布：

```
y = wx + b + ε        ε ~ N(0, σ²)
```

那么给定 x 时 y 服从以 `ŷ = wx + b` 为中心的正态分布：

```
p(y | x) = 1/√(2πσ²) · exp( -(y - ŷ)² / (2σ²) )
```

样本独立，联合似然是各自相乘：

```
L(w, b) = ∏ p(yᵢ | xᵢ)
```

连乘几百个小于 1 的数会下溢成 0，取对数转成求和：

```
log L = -n/2 · log(2πσ²)  -  1/(2σ²) · Σ(yᵢ - ŷᵢ)²
```

前一块是常数，后一块是平方和。所以：

```
最大化 log L  ⟺  最小化 Σ(yᵢ - ŷᵢ)²
```

实测扫 `w`（真值 3.0，5 个样本）：

| w | 残差平方和 | 对数似然 |
|---|---|---|
| 2.5 | 12.96 | -641.3 |
| 2.9 | 0.46 | -16.2 |
| **3.0** | **0.087** | **2.57** |
| 3.1 | 0.81 | -33.7 |
| 3.5 | 14.71 | -728.6 |

两列严格反向单调，极值在同一处。

**这个推导的价值在于：损失函数不是拍脑袋选的，它是噪声假设的产物。**

| 噪声假设 | 对应的损失 |
|---|---|
| 正态分布 | MSE |
| 拉普拉斯分布 | MAE，绝对值误差 |
| 伯努利分布 | 交叉熵（二分类） |
| 多项分布 | 交叉熵（softmax 回归） |

后两行就是 3.4 会讲的。语言模型最小化交叉熵，本质也是在最大化“给定上文出现下一个 token”的似然。

## 学习率：梯度只管方向，不管走多远

参数更新是 `θ ← θ - η·∇L`，那个 `η` 就是学习率。

为什么要乘一个系数，不能直接用梯度：

**梯度的大小取决于 loss 怎么写，但最优点不取决。**

```python
loss = ((pred - y) ** 2).mean()    # 梯度 = g
loss = ((pred - y) ** 2).sum()     # 梯度 = 1000g
```

同一份数据、同一个最优点，梯度差 1000 倍。如果直接用 `w -= grad`，换一种 loss 写法就崩了。所以要有一个外部系数把梯度换算成步长。

实测扫 lr（30 轮，真值 w=[2.0,-3.4]）：

| lr | 最终 loss | 状态 |
|---|---|---|
| 0.001 | 0.044 | 30 轮没走到底 |
| 0.01 | 0.000046 | 收敛 |
| 0.5 | 0.000047 | 收敛 |
| 1.0 | 0.000054 | 收敛，略差 |
| 1.5 | 0.000100 | 开始变差 |
| 2.0 | nan | 发散 |

临界点在 2.0 附近。这个问题的 loss 曲面曲率约等于 1，规律是 lr 超过 `2/曲率` 就震荡放大。

学习率叫**超参数**，因为它不在反向传播里算出来，要事先给定。梯度是算的，学习率是调的。

## 小批量随机梯度下降

三种做法的实测对比（1000 样本，10 轮）：

| batch | 更新次数 | 耗时 | 最终 loss |
|---|---|---|---|
| 1 | 10000 | 1.890 s | 0.000047 |
| 10 | 1000 | 0.184 s | 0.000047 |
| 100 | 100 | 0.019 s | 0.000718 |
| 1000（全量） | 10 | 0.002 s | 5.95 |

三个结论：

**batch=1 和 batch=10 精度一样，但慢十倍。** 单步耗时算一下：`1.890/10000 = 0.189 ms`，`0.184/1000 = 0.184 ms`，几乎相同。**小 batch 的代价不是每次更慢，而是需要更多次更新。**

**batch=1000 完全不收敛。** 10 轮只有 10 次更新，参数离真值很远。

**最优区间在中间。** 实际训练用 32 到 1024。

“随机”指的是每次随机采样哪些样本，靠 `shuffle` 实现：

```python
perm = torch.randperm(N)
idx = perm[i:i+batch_size]
```

不打乱的话模型会记住批次顺序，学到跟任务无关的模式。

## 矢量化：别用 for 循环遍历张量

同一件事（两个全 1 向量相加），两种写法：

| n | for 循环 | 矢量化 | 倍数 |
|---|---|---|---|
| 1,000 | 12.41 ms | 0.018 ms | 674× |
| 10,000 | 97.65 ms | 0.012 ms | 8138× |
| 1,000,000 | **10298 ms** | 0.488 ms | 21116× |

for 循环的耗时随 n 线性增长，矢量化几乎不变。100 万个数，前者 10 秒，后者 0.5 毫秒。

GPU 上更极端（n=10000）：

```
for 循环   697.5 ms
矢量化     0.051 ms
```

for 循环在 GPU 上比 CPU 还慢 7 倍，因为每次索引都要 CPU 和 GPU 同步一次。

常见改写：

```python
total += x[i]        →  x.sum()
if x[i] < 0: x[i]=0  →  torch.clamp(x, min=0)
if y[i] > 0.5: ...   →  (y > 0.5).float()
```

**代码里出现 `for i in range(len(张量))`，几乎一定有矢量化写法。**

有三类循环避免不了：模型层数（几十层，开销可忽略）、训练轮次、以及有前后依赖的（RNN 的时间步）。

## 从零实现里两个函数

### synthetic_data：为什么自己造数据

```python
def synthetic_data(w, b, num_examples):
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)
    return X, y.reshape((-1, 1))
```

实测：`features (1000,2)`，`labels (1000,1)`，噪声均值 0.00015、标准差 0.0099。

`reshape((-1,1))` 把 `(1000,)` 变成 `(1000,1)` 列向量，为了和模型输出形状对齐。

**自己造数据的原因是你知道正确答案。** 训练完看看学到的 w、b 是不是 `[2, -3.4]` 和 `4.2`，就能判断模型有没有学到规律。真实数据集没有这个参照。

### data_iter：手写一遍才知道 DataLoader 在干嘛

```python
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(
            indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]
```

四个动作：造索引、打乱、切批、按索引取行。

实测 `batch_size=32`，1000 个样本分成 32 批，前 31 批各 32 个，最后一批 8 个。

`min` 那里其实多余，Python 切片本来就会自动截断，`indices[992:1024]` 拿到的就是 `indices[992:1000]`。

**`yield` 是重点。** 它让函数变成生成器，每次交出一批然后暂停。内存里永远只有一批数据。改成 `return` 一个列表的话，数据集大了会直接把内存撑爆。

`features[batch_indices]` 是花式索引，按给定下标取行，顺序跟着索引走而不是排序后，这正是 shuffle 能生效的原因。

## 初始化：w 必须随机，b 可以全 0

```python
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
```

**b 的形状**：`(1,)` 和 `(1,1)` 都能和 `(1000,1)` 广播，`(2,1)` 会报错。

**w 为什么必须随机**，这里有个叫对称性破缺的概念。假设一个隐藏层有 4 个神经元，如果权重全初始化为 0，四个神经元的输出完全相同，反向传回的梯度也相同，更新后依然相同。**永远分不开，4 个单元等于 1 个。**

实测两层网络训练 50 步后比较四个单元的输出差异：

```
W1 全零初始化：  [0.0, 0.0, 0.0]           完全一样
W1 随机初始化：  [0.0428, 0.0342, 0.0584]   各不相同
```

**b 为什么能是 0**：每个神经元的 b 虽然都从 0 开始，但它们的输入不同（因为 w 各列不同），梯度自然不同，更新后就分开了。对称性问题只出在 w 上。

**为什么 w 要小（0.01）**：输入 784 维时，`N(0,1)` 初始化会让输出量级到 28 左右，几层放大后溢出，梯度跟着失控。

## sgd 函数三行各管一件事

```python
def sgd(params, lr, batch_size):
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()
```

**`no_grad` 不能省。** 去掉它直接报错：

```
RuntimeError: a leaf Variable that requires grad is being used in an in-place operation.
```

因为 `param` 是叶子张量，追踪梯度时不允许原地改它的数据。不加还会让计算图越滚越大。

**除以 `batch_size`** 是因为教材的 loss 用了 `.sum()` 而不是 `.mean()`。实测（lr=0.03，5 轮）：

```
除以 batch_size : w=[2.000, -3.400]  b=4.199
不除            : w=[1.909, -3.433]  b=4.070
```

不除等于把学习率放大 32 倍（0.03 → 0.96）。自己写的时候用 `.mean()` 就不用除。

**`zero_grad` 放在循环内**，每个参数更新完立刻清零，下一轮 `backward()` 才是全新梯度。放外面就变成累加，训练会卡住。

另外，老代码里的 `param.data -= ...` 现在不推荐，它会绕过版本计数，误用时会静默算错。`no_grad` 才是正确做法。

## 概念清单

### 模型与损失

| 概念 | 含义 |
|---|---|
| 仿射变换 | `y = Wx + b`。线性变换加平移，不满足 `f(0)=0` 和可加性，但深度学习沿用了“线性层”的叫法 |
| 齐次坐标 | 给输入补一个常数 1 并把 b 塞进矩阵（多一行 `[0,0,1]`），把仿射变换变成纯线性变换 |
| 似然 likelihood | 数据已知、参数未知，问哪组参数最能解释这组数据。方向和概率相反（概率是参数已知求数据） |
| 最大似然估计 | 选出让观测数据出现概率最大的参数。等价于最小化负对数似然 |
| 对数似然 | `log L = Σ log pᵢ`，pᵢ 是第 i 个样本在预测分布下出现的概率。取 log 是为了把连乘变求和，同时避免几百个小数相乘下溢成 0 |
| MSE | 均方误差 `(1/n)Σ(yᵢ-ŷᵢ)²`。在正态噪声假设下，最小化它就等于最大化似然 |
| 噪声假设与损失对应 | 正态→MSE，拉普拉斯→MAE，伯努利/多项→交叉熵。损失函数是噪声假设的产物，不是随便选的 |

### 训练与优化

| 概念 | 含义 |
|---|---|
| 学习率 lr | 步长系数，`θ ← θ - η·∇L`。梯度只管方向，它管走多远 |
| 超参数 | 不在反向传播中算出来、要事先给定的量，如 lr、batch_size、轮数。和“参数”（w、b）相对 |
| 全量梯度下降 | 每次用全部样本算梯度。方向准，但每步代价 O(N)，更新次数极少 |
| 小批量 SGD | 每次用几十到几百个样本。工业界的标准做法，兼顾更新频率和单步成本 |
| batch_size | 每批样本数。太小需要更多次更新（单步开销不变），太大更新次数不够，实测最优在 32 到 1024 |
| 对称性破缺 | 同一层权重全相同时，各神经元输出和梯度都相同，永远学不出差异。所以 w 必须随机初始化 |
| 叶子张量 | 用户直接创建的张量，`grad_fn` 为 None。追踪梯度时不允许对它做原地修改，必须用 `no_grad` |

### 数据与执行效率

| 概念 | 含义 |
|---|---|
| 矢量化 | 一次操作处理整个数组，不写逐元素循环。100 万元素时比 for 循环快 2 万倍 |
| 生成器 yield | 执行到 yield 交出值并暂停，下次从这里继续。内存中只保留当前一批数据 |
| 花式索引 | 用张量或列表当下标取行，`features[[7,3,9]]` 按给定顺序取。顺序不排序，这是 shuffle 生效的原因 |

### 数据集划分

| 概念 | 含义 |
|---|---|
| 训练集 / 验证集 / 测试集 | 训练集算梯度更新参数；验证集调超参数、选轮数、早停，可反复看；测试集只评一次。比例常见 6:2:2，数据量大时 98:1:1 |
| 信息泄漏 | 用测试集调超参数，等于把测试集信息带进模型。挑出的“最好结果”含运气成分，报出的分数虚高 |
